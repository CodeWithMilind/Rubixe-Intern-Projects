------------------------------------------------------------------------------

Null values: Removing nulls for TARGET=0 ensures only complete data is used for non-defaulters.

Unknowns / placeholders: Cleaning categorical unknowns improves model reliability.

Outliers: Removing extreme numeric values prevents skewed model learning, especially for non-defaulters.

After this cleaning, the dataset for TARGET=0 is more representative and stable.

This step is safe for highly imbalanced datasets because it focuses only on the majority class (non-defaulters), which will reduce noise without losing rare defaulters.
