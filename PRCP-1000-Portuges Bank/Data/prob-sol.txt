| Issue                                      | Why It Matters                                                         | How to Fix                                                                      |
| ------------------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| You treated `duration` as a normal feature | It leads to *data leakage* since duration is only known after the call | Drop it before training the model                                               |
| No encoding technique specified            | ML models can’t read strings                                           | Use Label Encoding for binary vars and One-Hot Encoding for multi-category vars |
| You only looked at correlation             | Correlation works only for numeric data                                | Also analyze categorical features vs target using `groupby` or `pd.crosstab()`  |
| No feature scaling                         | Some models (like Logistic, KNN, SVM) require scaling                  | Apply `StandardScaler()` or `MinMaxScaler()`                                    |
| No class balance check                     | Target `y` is highly imbalanced                                        | Use `SMOTE()` or `class_weight='balanced'`                                      |
| No model comparison yet                    | The final report requires model comparison                             | Train Logistic Regression, RandomForest, XGBoost, etc. and compare accuracies   |
| EDA report lacks summary                   | You didn’t conclude findings                                           | Write a clean insight summary after each step                                   |
